# Minitask Algoritma 3
## Membuat algoritma menghitung luas dan keliling lingkaran

```
1. Mulai
2. Masukkan nilai r atau jari-jarinya
3. Hitung luasnya dengan rumus 3,14 dikali 2 kali jari-jari
4. Hitung keliling lingkaran dengan rumus 2 dkali 3,14 dikali jari-jari
5. Tampilkan hasil dari luas dan keliling lingkaran
6. Selesai
```
